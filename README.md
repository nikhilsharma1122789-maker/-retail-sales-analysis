# Retail Sales Analysis — Nikhil Sharma

## Project overview
An entry-level data analytics portfolio project demonstrating a basic retail sales workflow:
- Dataset inspection and data preparation
- KPI calculation and business analysis
- SQL aggregations and filtering
- Interactive dashboard with region, category, and year filters

## Dataset
`data/retail_sales.csv` contains 1,200 synthetically generated order records for 2025.
The data is fictional and created for demonstration. Do not describe it as real company data.

## Files
- `data/retail_sales.csv` — source dataset
- `sql/retail_analysis.sql` — MySQL table definition and analytical queries
- `dashboard/index.html` — self-contained interactive dashboard (open in a browser)

## How to use
1. Open `dashboard/index.html` in Chrome, Edge, or Firefox.
2. Use the dropdown filters to explore region, category, and year.
3. Import `data/retail_sales.csv` into MySQL Workbench as `retail_sales`.
4. Run the queries in `sql/retail_analysis.sql`.
5. Validate that SQL totals match the dashboard totals for the same filters.

## Suggested portfolio write-up
**Objective:** Analyze retail sales performance to understand revenue, profitability, product/category contribution, and regional trends.

**Tools:** Microsoft Excel, MySQL, HTML/CSS/JavaScript dashboard.

**Analysis questions:**
1. What are total revenue, profit, order count, and profit margin?
2. Which categories and regions contribute most to revenue?
3. How does revenue change month over month?
4. Which products generate the most revenue?
5. How do discount bands relate to average profit?
